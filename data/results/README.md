# Public-Subset Result Files

These CSV files summarize evaluation results on the 1,049 public questions.

| File | Description |
| --- | --- |
| `overall_public.csv` | Standard no-tool accuracy for each evaluated model. |
| `by_main_discipline_public.csv` | Standard no-tool accuracy by main discipline. |
| `by_fine_discipline_public.csv` | Standard no-tool accuracy by fine-grained discipline label for each model. |
| `fine_summary_public.csv` | Mean accuracy across models for each fine-grained discipline label. |
| `full_vs_public.csv` | Comparison between full internal benchmark scores and public-subset scores. |
| `with_tool_public.csv` | Web-search-only with-tool accuracy on the public subset. |

All accuracies are fractions in `[0, 1]`.
