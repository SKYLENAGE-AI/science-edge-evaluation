# Assets

This directory contains presentation assets used by the README files, such as benchmark overview figures, example-question panels, and result plots.

The result plots currently include the 28-model standard-evaluation comparison (`accuracy_overall.png`), the 28-model visual-evidence ablation (`visual_evidence_ablation.png`), and the eleven-model tool-augmented visual-agent comparison with trajectory attribution (`tool_augmented_evaluation.png`).

Benchmark input images are stored in `../data/images/`, not in this directory.
